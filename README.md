# TypeScript Assignment

## Overview

This repository contains eight coding solutions provided by Next-Level. It also includes two blog posts discussing important TypeScript concepts.

The blog posts cover Type Alias vs Interface and Union and Intersection Types in TypeScript.

## Blog Posts

1. [Type Alias vs Interface in TypeScript](./type-vs-interface.md)

   Explains the differences between `type` aliases and `interface`, including their features and use cases.

2. [Combining Union and Intersection Types in TypeScript](./union-and-intersection-types.md)

   Explains how Union (`|`) and Intersection (`&`) types work together with a practical example.

## Coding Solutions

All eight coding solutions are implemented in `solutions.ts`.

The solutions cover basic TypeScript concepts, type narrowing, readonly tuples, generics, interfaces, classes, inheritance, and asynchronous programming with Promises.
